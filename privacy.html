PttChrome WebSocket 版隱私權政策

更新日期：2026-10-19。本網站由 leoislucky-git 維護，以 GPL-2.0 授權公開原始碼；原作者為 Chuck Yang。

擴充功能

本擴充功能由 leoislucky-git 維護，並非 PTT 官方或原作者發行。安裝啟用後，會協助本站直接連線 PTT／PTT2，沒有另外的操作面板。

擴充功能僅透過 Chrome 的 declarativeNetRequestWithHostAccess 權限套用固定規則：對 https://leoislucky-git.github.io 發起、連往 wss://ws.ptt.cc/bbs 或 wss://ws.ptt2.cc/bbs 的 WebSocket 連線，將 Origin 標頭設為 https://term.ptt.cc。其他請求不受影響；不會載入官方網頁的介面。

擴充功能不執行遠端程式碼、不收集或儲存使用者資料，也不讀取帳密、文章或瀏覽紀錄。沒有分析追蹤、資料出售或向維護者上傳資料。解除安裝即可移除連線規則；因未收集資料，沒有需向維護者申請刪除的資料。

瀏覽器設定與自動登入

偏好設定、黑名單與自行填寫的自動登入帳密，只儲存在此瀏覽器的網站資料中。帳密未加密；可清空自動登入欄位並關閉設定視窗以刪除帳密，或清除網站資料以刪除全部設定。

連線

網頁透過加密 WebSocket 直接連線 PTT／PTT2 官方伺服器，不經維護者的代理。登入帳密與終端機內容直接傳給所選 PTT 伺服器；PTT 也會收到連線 IP。使用 Chrome 時請安裝並啟用 PttChrome WebSocket 版擴充功能。

其他瀏覽器功能

複製、貼上與通知受瀏覽器權限限制；若右鍵貼上無法使用，請點回終端機按 Ctrl+V 或 Ctrl+Shift+V。圖片預覽、外部連結及分享按鈕可能連線至所選網站或原有第三方服務。

聯絡方式

隱私或功能問題請至 GitHub Issues 聯絡維護者；此管道公開，請勿張貼密碼或其他敏感資料。
